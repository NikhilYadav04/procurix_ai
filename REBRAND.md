# Rebrand — apply after the UI redesign

Decided 2026-09-02. Nothing here is applied yet.

---

## New name

**Procurix**

Chosen for the procure root plus the hard `-ix` ending, matching the Indian B2B
reference class (Moglix, Zetwerk) that IIT hackathon judges know.

---

## New page title and meta

```
Procurix — The AI Procurement Agent
```

```
Procurix runs your sourcing end to end — writes the RFP, runs the auction,
negotiates the price, and makes sure you never miss an MSME payment deadline.
```

Replaces "AI-Powered Procurement Copilot" and "AI writes, invites, and scores
for you." Copilot undersells it: the agent acts on its own now.

---

## New agent list for the homepage

Replaces the six in `src/pages/index.tsx` around line 676. Every line below is
backed by a tool that actually exists.

| # | Title | Description |
|---|---|---|
| 01 | Intake Analyst | Describe what you need in plain English |
| 02 | RFP Generator | Requirements become a ready-to-send RFP |
| 03 | Auction Manager | Vendors compete downward in a live reverse auction |
| 04 | Quote Reader | Replies are read, parsed and scored automatically |
| 05 | Negotiator | Drafts counter-offers, you approve before they send |
| 06 | Compliance Watch | Never miss India's 45-day MSME payment deadline |

**Removed: "Vendor Scout"** — it claimed to "automatically surface your best
suppliers". There is no supplier discovery; vendors are added by hand. The same
false claim was removed from the agent system prompt earlier.
